# BTC RADAR

منصة عربية متجاوبة لمراقبة وتحليل BTCUSDT باستخدام واجهات Binance العامة.

## ما تتضمنه النسخة الأولى
- سوق Spot وسوق USDT-M Futures.
- سعر مباشر عبر Binance WebSocket وتحديثات REST احتياطية.
- شموع 5m و15m و1h و4h و1d.
- EMA 20/50/200 وRSI 14.
- مستويات دعم ومقاومة تقديرية من القمم والقيعان المحلية.
- Funding Rate وOpen Interest ونسبة Long/Short عند اختيار Futures.
- دفتر أوامر مختصر.
- سيناريوهات مشروطة وحاسبة مخاطرة يدوية.
- تصميم عربي RTL ومتجاوب مع الهاتف.

## التشغيل
المشروع ثابت ولا يحتاج إلى تثبيت حزم. افتح index.html في متصفح حديث، أو انشر المستودع عبر GitHub Pages. يتطلب الاتصال بالإنترنت للوصول إلى Binance وGoogle Fonts.

## النشر عبر GitHub Pages
1. افتح Settings ثم Pages في المستودع.
2. من Build and deployment اختر GitHub Actions كمصدر.
3. ادفع أي تحديث إلى فرع main؛ سير العمل الموجود في .github/workflows/deploy.yml سينشر الموقع.
4. سيظهر رابط الموقع في صفحة Pages بعد اكتمال أول عملية نشر.

## الإعدادات المعتمدة
- الزوج: BTCUSDT
- الأسواق: Spot + Futures
- رأس المال المرجعي: 10,000 USDT
- نمط التشغيل: يدوي فقط، لا توجد أوامر تداول آلية.

## ملاحظات مهمة
- بيانات السوق مصدرها واجهات Binance العامة، وقد تتأثر بالاتصال أو حدود الطلبات أو توفر الخدمة.
- مستويات الدعم والمقاومة وقراءة الاتجاه استنتاجات حسابية وليست ضمانًا.
- حاسبة المخاطرة تقديرية ولا تشمل الرسوم أو الانزلاق أو التمويل.
- هذه الأداة للمعلومات والتعليم وليست توصية استثمارية.
